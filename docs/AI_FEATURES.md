# NetCaptor AI功能文档

## 概述

NetCaptor现已集成AI大模型功能，提供智能化的网页自动化和数据处理能力。通过AI组件，用户可以使用自然语言描述任务，让AI自动分析页面并执行相应操作。

## AI模型管理

### 设置位置
- 打开设置面板 → "🤖 AI模型" 标签页

### 支持的AI供应商
- **OpenAI**: GPT-3.5/GPT-4系列模型
- **Anthropic**: Claude系列模型  
- **Azure OpenAI**: 企业级OpenAI服务
- **自定义**: 兼容OpenAI API格式的其他服务

### 配置步骤
1. 选择AI供应商
2. 输入模型名称（如：gpt-4, claude-3-sonnet）
3. 配置API Key
4. 设置Base URL（可选，用于自定义端点）
5. 点击"测试"验证连接
6. 设置默认模型和参数

## AI组件类型

### 🤖 AI数据分析类

#### AI数据提取 (ai_extract_data)
- **功能**: 智能分析页面DOM，根据自然语言描述提取数据
- **配置项**:
  - AI模型: 选择使用的AI模型
  - 提示词: 描述要提取的数据，如"提取所有商品信息，包括名称、价格、链接"
  - 输出格式: JSON/CSV/纯文本
  - 保存变量: 提取结果保存的变量名
- **使用场景**: 
  - 电商网站商品信息提取
  - 新闻列表数据采集
  - 表格数据结构化提取

#### AI内容分析 (ai_analyze_content)
- **功能**: 分析页面内容结构，识别页面元素类型
- **配置项**:
  - AI模型: 选择使用的AI模型
  - 分析任务: 描述分析需求，如"分析页面结构，识别导航菜单和内容区域"
  - 保存变量: 分析结果保存的变量名
- **使用场景**:
  - 页面结构理解
  - 内容分类识别
  - 布局分析

#### AI数据验证 (ai_validate_data)
- **功能**: 验证提取的数据是否符合预期格式和要求
- **配置项**:
  - AI模型: 选择使用的AI模型
  - 数据来源: 要验证的数据变量名
  - 验证规则: 描述验证要求，如"检查是否包含必填字段，价格格式是否正确"
  - 保存变量: 验证结果保存的变量名
- **使用场景**:
  - 数据质量检查
  - 格式验证
  - 完整性校验

#### AI数据转换 (ai_transform_data)
- **功能**: 将数据转换为指定格式或结构
- **配置项**:
  - AI模型: 选择使用的AI模型
  - 数据来源: 原始数据变量名
  - 转换指令: 描述转换要求，如"将商品数据转换为标准CSV格式"
  - 输出格式: JSON/CSV/XML
  - 保存变量: 转换结果保存的变量名
- **使用场景**:
  - 数据格式标准化
  - 结构重组
  - 数据清洗

### 🤖 AI浏览器控制类

#### AI智能点击 (ai_smart_click)
- **功能**: 根据自然语言描述智能识别并点击页面元素
- **配置项**:
  - AI模型: 选择使用的AI模型
  - 点击描述: 描述要点击的元素，如"点击登录按钮"
  - 等待时间: 等待元素出现的时间(ms)
- **使用场景**:
  - 动态按钮点击
  - 复杂页面导航
  - 智能交互

#### AI表单填写 (ai_form_fill)
- **功能**: 智能理解表单结构并自动填写
- **配置项**:
  - AI模型: 选择使用的AI模型
  - 填写指令: 描述填写要求，如"填写用户名admin，密码123456"
  - 数据来源: 可选，从变量获取填写数据
- **使用场景**:
  - 自动登录
  - 表单批量填写
  - 注册流程自动化

#### AI智能导航 (ai_navigation)
- **功能**: 根据描述智能找到并点击导航元素
- **配置项**:
  - AI模型: 选择使用的AI模型
  - 导航描述: 描述导航目标，如"找到并点击产品中心菜单"
  - 等待时间: 等待元素出现的时间(ms)
- **使用场景**:
  - 网站导航
  - 菜单操作
  - 页面跳转

## 工作流程示例

### 智能数据提取流程
1. **导航到目标页面** (navigate)
2. **AI内容分析** (ai_analyze_content) - 理解页面结构
3. **AI数据提取** (ai_extract_data) - 提取所需数据
4. **AI数据验证** (ai_validate_data) - 验证数据质量
5. **AI数据转换** (ai_transform_data) - 转换为目标格式
6. **保存数据** (save_data) - 保存到文件

### 智能表单操作流程
1. **导航到登录页面** (navigate)
2. **AI表单填写** (ai_form_fill) - 自动填写登录信息
3. **AI智能点击** (ai_smart_click) - 点击登录按钮
4. **AI智能导航** (ai_navigation) - 导航到目标页面
5. **AI数据提取** (ai_extract_data) - 提取页面数据

## 最佳实践

### 提示词编写技巧
1. **具体明确**: 详细描述要提取的数据字段和格式
2. **结构化**: 使用JSON格式描述复杂数据结构
3. **示例驱动**: 提供期望输出的示例
4. **错误处理**: 描述异常情况的处理方式

### 性能优化
1. **模型选择**: 根据任务复杂度选择合适的模型
2. **提示词优化**: 简洁明确的提示词可提高响应速度
3. **缓存策略**: 相似页面可复用分析结果
4. **批量处理**: 合并多个简单任务减少API调用

### 错误处理
1. **连接检查**: 确保AI服务连接正常
2. **超时设置**: 设置合理的超时时间
3. **降级策略**: AI失败时使用传统选择器
4. **日志记录**: 记录AI调用结果用于调试

## 注意事项

1. **API费用**: AI调用会产生费用，请合理使用
2. **数据隐私**: 页面内容会发送给AI服务商，注意隐私保护
3. **网络依赖**: 需要稳定的网络连接访问AI服务
4. **模型限制**: 不同模型有不同的上下文长度限制
5. **准确性**: AI结果可能不完全准确，建议添加验证步骤

## 故障排除

### 常见问题
1. **AI调用失败**: 检查API Key和网络连接
2. **元素未找到**: 优化提示词描述或添加等待时间
3. **数据格式错误**: 在提示词中明确指定输出格式
4. **性能较慢**: 选择更快的模型或优化提示词

### 调试技巧
1. 查看工作流执行日志
2. 测试AI模型连接
3. 验证页面DOM结构
4. 逐步调试工作流节点
