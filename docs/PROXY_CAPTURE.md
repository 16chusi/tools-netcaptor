# 代理抓包功能说明

## 📋 功能概述

通过在本地启动一个 HTTP/HTTPS 代理服务器，拦截和分析所有通过该代理的网络请求。用户可以查看请求的详细信息，包括请求头、请求体、响应头、响应体等，并可以对请求进行修改和重放。

## 🏗️ 架构设计

```
客户端 (浏览器, App) → 本地代理服务器 (Go) → 目标服务器
                  ↑
                  ↓
前端 (Vue) ↔ Go 后端 (Wails)
```

### 核心文件

**后端 (Go)**
- `proxy_server.go` - 代理服务器核心逻辑
- `cert_manager.go` - 证书生成和管理
- `interceptor.go` - 请求拦截和修改
- `network_capture.go` - 抓包数据显示

**前端 (Vue)**
- `NetworkCapture.vue` - 抓包数据显示界面
- `RequestTab.vue`, `ResponseTab.vue`, `HeadersTab.vue`, `CookiesTab.vue` - 请求/响应详情的各个标签页

## 🎯 主要功能

| 功能 | 说明 |
|---|---|
| **HTTP/HTTPS 抓包** | 拦截和分析 HTTP/HTTPS 流量 |
| **证书管理** | 自动生成和安装根证书，以便解密 HTTPS 流量 |
| **请求/响应详情** | 查看完整的请求和响应报文 |
| **请求过滤** | 根据域名、URL、方法等过滤请求 |
| **请求拦截** | 修改请求/响应内容 |
| **重放攻击** | 重放指定的网络请求 |

### 请求拦截与修改

拦截功能允许用户根据预设规则，在响应返回时自动修改其内容。这对于调试和测试非常有帮助。当前版本主要支持在 **响应阶段** 进行拦截。

#### 1. 替换响应 (Response Replace & Find/Replace)

你可以替换整个响应体，或者在响应体中查找并替换特定内容。

- **完全替换 (`responseReplace`)**: 将整个响应体替换为你在规则中定义的固定内容。这对于模拟API返回特定数据（如成功或失败的JSON）非常有用。
    - *示例*: 将一个API的响应直接替换为 `{"status": "mocked", "data": 123}`。

- **查找并替换 (`findReplace`)**: 在响应体中查找文本或使用正则表达式进行匹配，并将其替换为新的内容。
    - *示例*: 将返回的HTML中的 `</body>` 替换为 `<script>alert('injected')</script></body>`，从而注入自定义脚本。

#### 2. 重定向 (Redirect)

你可以将一个请求重定向到另一个 **URL**。

- **API域名切换**: 将所有对 `api.production.com` 的请求重定向到测试环境的 `api.staging.com`。
- **版本切换**: 将对 `v1/user` 的请求重定向到 `v2/user`，以测试新版API的兼容性。

> **注意**: 当前版本不支持将请求重定向到本地文件系统（如 `file:///...`），也不支持在请求过程中设置断点进行手动修改。

## 🚀 使用流程

### 1. 启动代理服务器
- 在应用中，进入“网络抓包”页面。
- 点击“启动代理”按钮，应用会在本地默认端口（如 8888）启动一个代理服务器。

### 2. 安装根证书
- 如果是首次使用，需要安装根证书以抓取 HTTPS 流量。
- 点击“下载证书”按钮，下载 `netcaptor-ca.crt` 证书文件。
- **Windows**: 双击证书文件 -> 安装证书 -> 选择“受信任的根证书颁发机构”。
- **macOS**: 双击证书文件 -> 在“钥匙串访问”中找到 `NetCaptor CA` -> 右键“显示简介” -> “信任” -> “使用此证书时”选择“始终信任”。

### 3. 配置系统/浏览器代理
- 将你的操作系统或浏览器的代理设置为 `127.0.0.1:8888`。
- **Windows**: 设置 -> 网络和 Internet -> 代理 -> 手动设置代理。
- **macOS**: 系统偏好设置 -> 网络 -> 高级 -> 代理 -> 勾选“Web 代理(HTTP)”和“安全 Web 代理(HTTPS)”。
- **浏览器插件**: 可以使用如 `Proxy SwitchyOmega` 等插件来方便地切换代理。

### 4. 开始抓包
- 配置好代理后，所有通过该代理的网络流量都会显示在 NetCaptor 的界面上。
- 你可以点击任意一条记录查看详细信息。

### 5. 使用高级功能
- **过滤**: 在顶部的过滤栏输入关键字，可以实时过滤请求。
- **拦截**: 在“拦截规则”中设置匹配规则，当请求匹配时，可以暂停请求，手动修改后再发送。

## ⚠️ 注意事项

1.  **证书信任**: 必须正确安装并信任根证书，否则无法抓取 HTTPS 流量。
2.  **代理设置**: 确保你的设备或应用的网络流量经过了 NetCaptor 的代理端口。
3.  **应用关闭**: 关闭 NetCaptor 应用后，记得关闭系统代理，否则可能无法上网。
4.  **敏感信息**: 抓包会捕获所有流量，包括可能存在的密码、令牌等敏感信息，请谨慎使用。

## 🐛 调试

- **无法抓包**:
    - 检查代理是否设置正确。
    - 检查防火墙是否阻止了应用的网络连接。
- **HTTPS 网站证书错误**:
    - 确认根证书是否已正确安装并信任。
    - 尝试重新生成并安装证书。
- **应用崩溃**:
    - 查看 `app.log` 文件获取详细错误信息。
