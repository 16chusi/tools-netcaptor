# 网络代理设置功能

## 功能概述

NetCaptor 现在支持配置网络代理，允许所有网络请求（包括AI模型调用、工作流中的HTTP请求等）通过指定的代理服务器进行。

## 功能特性

### 1. 代理类型支持
- **HTTP代理**: 标准HTTP代理协议
- **HTTPS代理**: 支持HTTPS代理
- **SOCKS5代理**: 支持SOCKS5协议

### 2. 认证支持
- 支持用户名/密码认证
- 可选择启用或禁用认证

### 3. 绕过列表
- 配置不需要通过代理的地址
- 支持通配符匹配（如 `*.local`）
- 默认绕过本地地址（localhost, 127.0.0.1等）

### 4. 连接测试
- 内置代理连接测试功能
- 实时验证代理配置是否正确

## 使用方法

### 1. 打开设置面板
在主界面点击设置按钮，选择 "🌐 网络代理" 标签页。

### 2. 基本配置
1. **启用网络代理**: 勾选此选项以启用代理功能
2. **代理类型**: 选择 HTTP、HTTPS 或 SOCKS5
3. **代理服务器地址**: 输入代理服务器的IP地址或域名
4. **端口**: 输入代理服务器端口号

### 3. 认证配置（可选）
如果代理服务器需要认证：
1. 启用 "认证" 选项
2. 输入用户名和密码

### 4. 绕过列表配置
在绕过代理的地址框中，每行输入一个地址或模式：
```
localhost
127.0.0.1
*.local
192.168.*
```

### 5. 测试连接
配置完成后，点击 "测试连接" 按钮验证代理设置是否正确。

## 配置示例

### HTTP代理示例
```
代理类型: HTTP
服务器地址: proxy.company.com
端口: 8080
认证: 启用
用户名: myuser
密码: mypass
```

### SOCKS5代理示例
```
代理类型: SOCKS5
服务器地址: 127.0.0.1
端口: 1080
认证: 禁用
```

## 影响范围

启用代理后，以下功能将通过代理服务器进行网络请求：

1. **AI模型调用**
   - OpenAI API调用
   - Claude API调用
   - 其他AI服务调用

2. **工作流网络操作**
   - HTTP请求组件
   - 下载文件组件
   - 其他需要网络访问的组件

3. **代理连接测试**
   - 内置的连接测试功能

## 配置存储

代理配置保存在用户主目录下的 `.netcaptor/proxy_config.json` 文件中，包含以下信息：
- 代理启用状态
- 代理类型和服务器信息
- 认证配置（密码会被保存，请注意安全）
- 绕过列表

## 注意事项

1. **安全性**: 代理密码会以明文形式保存在配置文件中，请确保文件权限设置正确
2. **性能**: 使用代理可能会影响网络请求的速度
3. **兼容性**: 确保代理服务器支持所需的协议类型
4. **绕过列表**: 合理配置绕过列表可以提高本地访问的性能

## 故障排除

### 连接测试失败
1. 检查代理服务器地址和端口是否正确
2. 验证认证信息是否正确
3. 确认代理服务器是否正常运行
4. 检查网络连接是否正常

### AI调用失败
1. 确认代理服务器支持HTTPS流量
2. 检查代理服务器是否允许访问AI服务的域名
3. 验证代理配置是否正确应用

### 工作流执行异常
1. 检查目标URL是否在绕过列表中（如果不需要代理）
2. 确认代理服务器稳定性
3. 查看错误日志获取详细信息
