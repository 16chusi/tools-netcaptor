# 工作流导航功能测试文档

## 测试目标
验证"开始 -> 导航 -> 结束"工作流的完整执行流程。

## 前置条件
1. WebSocket 服务器已启动
2. 浏览器插件已安装并连接
3. 工作流画布已创建任务

## 测试步骤

### 1. 创建工作流
- 打开工作流编排界面
- 创建新任务
- 画布上已有"开始"和"结束"节点

### 2. 添加导航节点
- 从左侧节点面板拖拽"导航"节点到画布
- 放置在"开始"和"结束"节点之间
- 连接: 开始 -> 导航 -> 结束

### 3. 配置导航节点
- 点击"导航"节点
- 在右侧属性面板输入 URL: `https://www.baidu.com`
- 点击"保存"

### 4. 执行工作流
- 点击工具栏的"▶️ 运行"按钮
- 观察执行状态

## 预期结果
1. 状态显示"运行中"
2. 浏览器自动打开新标签页
3. 导航到百度首页
4. 状态变为"成功"
5. 显示执行步骤: 1/1

## 可能的问题

### 问题 1: 导航节点未保存数据
**现象**: 点击运行后提示"缺少 URL 参数"

**原因**: PropertyPanel 保存的数据未正确更新到节点

**解决方案**: 修复 FlowCanvas.vue 的 onSaveNodeData 方法

### 问题 2: WebSocket 未连接
**现象**: 执行超时，无响应

**原因**: 浏览器插件未连接到 WebSocket 服务器

**解决方案**: 
1. 检查 WebSocket 服务器是否启动
2. 在插件 popup 中手动连接

### 问题 3: 导航命令未执行
**现象**: 浏览器未打开新标签页

**原因**: background.js 的 executeNavigate 方法可能有问题

**解决方案**: 检查浏览器控制台日志
