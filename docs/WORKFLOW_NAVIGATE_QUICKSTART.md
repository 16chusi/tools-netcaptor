# 工作流导航功能快速开始

## 🚀 5分钟快速测试

### 步骤 1: 启动服务
```bash
cd tools-netcaptor
./run.sh
```

### 步骤 2: 启动 WebSocket 服务器
1. 在应用主界面，点击工具栏的 WebSocket 按钮
2. 确认 WebSocket 服务器已启动（显示端口号）

### 步骤 3: 安装并连接浏览器插件
1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 启用"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `chrome-extension` 目录
6. 点击插件图标，输入 WebSocket 端口号
7. 点击"连接"按钮

### 步骤 4: 创建工作流
1. 在应用中点击"🔄 任务流"按钮
2. 点击"+ 新建任务"
3. 画布上会自动创建"开始"和"结束"节点

### 步骤 5: 添加导航节点
1. 从左侧面板拖拽"🌐 导航"节点到画布中间
2. 连接节点：
   - 从"开始"节点底部的连接点拖拽到"导航"节点顶部
   - 从"导航"节点底部拖拽到"结束"节点顶部

### 步骤 6: 配置导航节点
1. 点击"导航"节点
2. 在右侧属性面板输入：
   - 目标URL: `https://www.baidu.com`
3. 点击"保存"按钮

### 步骤 7: 保存并运行
1. 点击工具栏的"💾 保存"按钮
2. 点击"▶️ 运行"按钮
3. 观察执行过程

## ✅ 预期结果

1. **状态显示**
   - 工具栏右侧显示: `1/1 运行中`
   - 导航节点边框变红（高亮显示）

2. **浏览器行为**
   - 自动打开新标签页
   - 导航到百度首页
   - 页面加载完成

3. **执行完成**
   - 状态变为: `1/1 成功`
   - 节点高亮消失

## 🐛 故障排查

### 问题 1: 点击运行后无反应
**检查项**:
- [ ] WebSocket 服务器是否启动？
- [ ] 浏览器插件是否已连接？
- [ ] 浏览器控制台是否有错误？

**解决方法**:
```bash
# 查看后端日志
tail -f app.log | grep -E "Workflow|WebSocket"
```

### 问题 2: 提示"缺少 URL 参数"
**原因**: 导航节点未保存配置

**解决方法**:
1. 重新点击导航节点
2. 确认 URL 已填写
3. 点击"保存"按钮
4. 再次点击"💾 保存"保存整个任务

### 问题 3: 执行超时
**原因**: 浏览器插件未响应

**解决方法**:
1. 打开 `chrome://extensions/`
2. 找到 NetCaptor 插件
3. 点击"Service Worker"查看日志
4. 检查是否有错误信息

### 问题 4: 浏览器未打开新标签页
**原因**: 插件权限不足或未激活

**解决方法**:
1. 确认插件已启用
2. 刷新插件（关闭再打开）
3. 重新连接 WebSocket

2. 切换到 Console 标签
3. 筛选 `[FlowCanvas]` 或 `[WorkflowDrawer]`

## 📝 注意事项

1. **URL 格式**: 必须包含协议（http:// 或 https://）
2. **超时时间**: 默认 15 秒，如果页面加载慢可能超时
3. **多标签页**: 每次执行都会打开新标签页
4. **权限要求**: 插件需要 `tabs` 权限
