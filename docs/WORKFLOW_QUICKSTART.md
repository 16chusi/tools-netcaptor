# 工作流执行 - 快速开始指南

## 🚀 5 分钟快速体验

### 步骤 1: 启动应用

```bash
cd tools-netcaptor
./run.sh
```

### 步骤 2: 加载浏览器插件

1. 打开 Chrome 浏览器
2. 访问 `chrome://extensions/`
3. 开启"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择 `chrome-extension` 目录

### 步骤 3: 连接插件到应用

1. 点击 Chrome 工具栏的 NetCaptor 插件图标
2. 在弹出窗口中，输入 WebSocket 端口号（应用启动时会显示）
3. 点击"连接"按钮
4. 看到"已连接"状态

### 步骤 4: 创建第一个工作流

1. 在 NetCaptor 应用中，点击"🔄 任务流编排"按钮
2. 点击左侧"+ 新建"按钮，创建新任务
3. 从左侧面板拖拽节点到画布：
   - 已有"开始"和"结束"节点
   - 拖拽"🌐 导航"节点到中间
   - 拖拽"⏱️ 等待"节点到导航后面

### 步骤 5: 连接节点

1. 鼠标悬停在"开始"节点上，会显示连接点
2. 从"开始"节点底部的连接点拖拽到"导航"节点顶部
3. 继续连接：导航 → 等待 → 结束

### 步骤 6: 配置节点

1. 点击"导航"节点
2. 在右侧属性面板中输入：
   - URL: `https://example.com`
3. 点击"保存"

4. 点击"等待"节点
5. 在属性面板中输入：
   - 等待时间: `2000` (毫秒)
6. 点击"保存"

### 步骤 7: 执行工作流

1. 点击顶部工具栏的"▶️ 运行"按钮
2. 观察：
   - 状态显示"1/3 运行中"
   - 当前执行的节点会有红色边框高亮
   - Chrome 会自动打开 example.com
   - 等待 2 秒后完成
   - 状态显示"3/3 成功"

### 步骤 8: 保存工作流

1. 点击"💾 保存"按钮
2. 工作流会保存到本地存储

## 🎯 进阶示例

### 示例 1: 自动填写表单

创建流程：
```
开始
  ↓
导航 (https://example.com/login)
  ↓
等待 (1000)
  ↓
输入文本 (#username, "testuser")
  ↓
输入文本 (#password, "123456")
  ↓
点击元素 (#login-button)
  ↓
等待 (2000)
  ↓
结束
```

配置说明：
- **导航节点**: URL 填写登录页面地址
- **输入文本节点**: 
  - selector: CSS 选择器（如 `#username`）
  - text: 要输入的文本
- **点击元素节点**:
  - selector: 按钮的 CSS 选择器

### 示例 2: 多页面操作

```
开始
  ↓
导航 (https://example.com/page1)
  ↓
等待 (1000)
  ↓
点击元素 (.next-page)
  ↓
等待 (2000)
  ↓
点击元素 (#submit)
  ↓
结束
```

## 💡 使用技巧

### 1. 获取 CSS 选择器
- 在 Chrome DevTools 中右键元素
- 选择 "Copy" → "Copy selector"
- 粘贴到节点配置中

### 2. 调整等待时间
- 页面加载慢时增加等待时间
- 建议在导航后等待 1-2 秒
- 在点击后等待 500-1000 毫秒

### 3. 调试技巧
- 先创建简单流程测试
- 逐步添加节点
- 观察控制台日志
- 使用"停止"按钮中断执行

### 4. 节点命名
- 双击节点可以重命名（如果支持）
- 使用有意义的名称便于理解

## ⚠️ 常见问题

### Q: 点击"运行"没反应？
A: 检查：
1. WebSocket 是否已连接（查看插件状态）
2. 节点是否已正确连接
3. 是否有"开始"节点

### Q: 执行失败提示"元素未找到"？
A: 检查：
1. CSS 选择器是否正确
2. 页面是否已加载完成（增加等待时间）
3. 元素是否在 iframe 中（暂不支持）

### Q: 如何停止正在执行的流程？
A: 点击"⏹️ 停止"按钮

### Q: 工作流保存在哪里？
A: 保存在浏览器的 localStorage 中

## 📚 节点参考

| 节点 | 参数 | 说明 |
|------|------|------|
| 开始 | 无 | 流程起点 |
| 导航 | url | 打开指定网址 |
| 点击元素 | selector | 点击页面元素 |
| 输入文本 | selector, text | 在输入框中输入文本 |
| 等待 | duration | 等待指定毫秒数 |
| 结束 | 无 | 流程终点 |
