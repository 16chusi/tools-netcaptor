## 🚀 快速开始

1. 阅读 **`USAGE.md`** 了解基本操作
2. 参考 **`NETWORK_CAPTURE.md`** 开始网络监控
3. 查看 **`PROXY_CAPTURE.md`** 配置HTTPS抓包

### 2. AI功能 (推荐新功能)
1. 阅读 **`AI_FEATURES.md`** 了解AI组件使用
2. 参考 **`AI_INTEGRATION_OVERVIEW.md`** 理解技术架构
3. 按照指南配置AI模型并创建智能工作流

### 3. 工作流开发
1. 学习 **`WORKFLOW_NODE_DEVELOPMENT.md`** 
2. 参考 **`AI_COMPONENT_DEVELOPMENT.md`** 开发AI组件
3. 使用 **`NESTED_LOOP_DEVELOPMENT_GUIDE.md`** 处理复杂逻辑

## ✨ 功能特性

### 核心功能
- 🌐 **网络抓包**: HTTP/HTTPS请求监控和分析
- 🔄 **工作流编排**: 可视化自动化任务设计
- 🤖 **AI智能化**: 自然语言驱动的智能操作 (新增)
- 🔧 **浏览器控制**: Chrome扩展深度集成
- 📊 **数据处理**: 多格式数据提取和转换

### AI功能亮点
- **智能数据提取**: 用自然语言描述提取需求
- **智能浏览器控制**: AI理解页面结构自动操作
- **多AI供应商支持**: OpenAI、Claude、Azure等
- **数据验证转换**: AI驱动的数据质量保证
- **自然语言交互**: 降低技术门槛，提升效率
